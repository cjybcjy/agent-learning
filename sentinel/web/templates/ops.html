MGFS 治理链路
把外部信号、Agent 建议、人工配置和批量验证分开呈现
01 1 待复核事项 把外部信号、Agent 建议和配置确认合并成一张人工队列。 输入: snapshot + suggestion + proposal 输出: review queue 02 2 配置规则 配置控制台承接人工判断，Schema 校验通过后才保存 YAML。 判断: approve / reject / edit 输出: 可热加载配置 03 3 执行巡检 Pipeline 读取股票池，逐标的运行 MGFS 评分并保存批次结果。 输入: moat_static_base 输出: pipeline batch 04 4 历史回测 回测和研究工件校验回答“评分是否可信、是否有未来函数污染”。 验证: point-in-time 输出: 回测可信度 05 5 回写假设 回测结果不会自动改分，只作为下一轮 YAML 复核输入。 边界: research_only 输出: 人工决策
