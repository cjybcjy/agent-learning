共整合 20 个工程补丁

存储层（6 个决策）
  1. SQLite WAL 模式（PRAGMA journal_mode=WAL）
  2. Rollup 预计算：rollup_30min / rollup_4h / rollup_daily（日级基于 4h 累加，O(1)）
  3. ai_signals 结构化：anomaly_score, sentiment_shift, key_driver, driver_keywords
  4. 基本面预留字段：pe_ratio, pb_ratio, roe_ttm, dividend_yield
  5. ai_call_log 表（成本护栏持久化）
  6. asyncio.Queue 缓冲 + File-based DLQ 降级 + 单协程 BatchWriter
采集层（3 个决策）
  1. Rate Limiter 按 domain:proxy_ip 维度隔离
  2. Proxy Pool 冷却期机制（失败 3 次 → cooldown 10 分钟 → 自动恢复）
  3. Collector 只写 Queue，不直接写库
AI 引擎（6 个决策）
  1. 真实语料注入：Top 10 代表性帖子作为 Prompt 上下文
  2. 即时 α 触发：EMA 平滑（跨日同时段），挂在 rollup_30min
  3. 成本护栏：MAX_AI_CALLS_PER_DAY 令牌桶，超预算后 UI 标红
  4. API 级 JSON 强制约束（response_format / tool_choice）
  5. 冻结 NLP 模型（.pkl 序列化），禁止在线 TF-IDF
  6. 未来函数防范：离线训练严格时间截面对齐
Web API（2 个决策）
  1. 强制分页：/api/heatmap 默认 limit=50，支持游标分页
  2. WebSocket 按市场订阅推送（含 heartbeat）
前端（3 个决策）
  1. AI 聊天隐式携带上下文
  2. WebSocket 指数退避重连 + 断线补齐
  3. React + 热度榜单 + 趋势图 + AI 面板常驻
