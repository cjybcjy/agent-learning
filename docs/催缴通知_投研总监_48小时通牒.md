## 需要提供的数据

### 格式：YAML（每只股票一个条目）

文件路径：`config/moat_static_base.yaml`

```yaml
version: "1.0"
scoring_weights:
  base: { weight: 0.4 }
  trend: { weight: 0.35 }
  safety: { weight: 0.25 }

companies:
  "600519":  # 股票代码，不带市场后缀
    name: "贵州茅台"
    sector: "白酒"
    base_score:
      brand_premium:       { score: 95, note: "国酒地位，品牌溢价极高" }
      franchise_barrier:   { score: 90, note: "产地壁垒，离开茅台镇无法复制" }
      switching_cost:      { score: 75, note: "商务宴请场景依赖" }
      network_effect:      { score: 50, note: "无显著网络效应" }
      cost_advantage:      { score: 70, note: "毛利率 90%+，定价权极强" }

  "000333":
    name: "美的集团"
    sector: "家电"
    base_score:
      brand_premium:       { score: 80, note: "家电龙头，品牌认知度高" }
      franchise_barrier:   { score: 65, note: "渠道壁垒深厚" }
      switching_cost:      { score: 60, note: "智能家居生态绑定" }
      network_effect:      { score: 45, note: "微弱" }
      cost_advantage:      { score: 85, note: "规模效应 + 供应链整合" }
```

### 评分维度说明（每项 0-100 分）

| 维度 | 含义 | 高分特征 |
|------|------|----------|
| brand_premium | 品牌溢价 | 定价权、消费者心智占领 |
| franchise_barrier | 特许经营壁垒 | 牌照、专利、产地、资源独占 |
| switching_cost | 转换成本 | 客户迁移成本、生态锁定 |
| network_effect | 网络效应 | 用户越多价值越大（平台型） |
| cost_advantage | 成本优势 | 规模效应、工艺领先、资源成本 |

**建议：首期聚焦 "白酒" 和 "出海制造" 两大板块，各选 5-10 只核心标的即可。**
